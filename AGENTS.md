# Enlace

Enlace is a model-independent, research-first application connection SDK with CLI and MCP transports.

- Keep the core independent of Pi, Warp, model providers, browsers and personal configuration.
- Adapters are trusted host code. Never load modules, commands or credentials supplied by a tool request.
- Research records evidence, not authority or permission. Writes require a host authorization callback for the exact stored plan.
- Preserve bounded I/O, cancellation, public-network defaults, explicit local opt-in, no automatic retries and no automatic backend fallback.
- Do not commit credentials, profiles, local inventories, vendor runtimes or machine-specific paths.
- Run npm test and npm run check for relevant code changes; keep examples and schemas aligned with implementation.
